# Terraform_Project_Part-1
Terraform Infrastructure Design : Create Terraform code for the following AWS setup: Internet → ALB → ECS/Fargate → RDS  Terraform should include: ● VPC with public &amp; private subnets ● ALB security group ● ECS/Fargate security group ● RDS security group ● ECS cluster, task definition and service ● RDS PostgreSQL or MySQL. RDS must be private and should only be accessible from ECS/Fargate.
The application container can use any simple Docker image such as Nginx or a placeholder backend service.
